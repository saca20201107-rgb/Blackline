Уравнения — крутишь, решение за секунду

Без графика. Только ползунки и шаги решения.
Как это работает?
Крутишь ползунок — коэффициент меняется, и всё решение переписывается за секунду. Не надо вводить и нажимать «решить».
• Линейное: ax + b = 0 → x = -b / a
• Квадратное: D = b² - 4ac, потом корни по формуле
• Кубическое: сначала ищем целый корень, делим, остаётся квадратное
